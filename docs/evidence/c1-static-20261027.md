# First executable static transaction/signal core, 2026-10-27

This is the bounded C1.2a/b slice plus the first C1.4 reference comparison,
built on the accepted API checkpoint `ef3c4f8`. It is not Stage 1 exit.

## Implemented

`HeadlessRuntime` owns a static signal graph on one thread. Transactions read
staged cells and derivations, evaluate private candidates, then publish settled
values atomically. Equality cuts off propagation; affected derivations evaluate
at most once in a publication pass. Revisions advance only for unequal commits.
`Cell.snapshot` refuses an unequal staged value so intermediate text cannot be
associated with a later committed revision.

Scoped refusal rolls back its writes, new graph caches and after-commit hooks;
outer staging survives. Defects crossing runtime boundaries poison the entire
transaction even when caught. Nested transactions join. Derivation failures are
values and can recover; reading a failure as a value poisons the transaction.

Observers see committed values. Effects queue initially and on unequal commits,
and each runs in its own transaction. A failing effect preserves prior commits.
Explicit bounded draining reports remaining work without claiming a cycle.
Cancellation removes queued effects; closing the driver releases its graph.
Thread, expired-capability and read-only-phase guards cover captured references.
The after-commit hook exercises rollback of prospective starts; it is not a
command scheduler.

Each reference property runs 300 generated programs of 30 transactions:
**9,000 transactions per platform, 18,000 total**. The independent model imports
no engine implementation and recomputes integer expressions from scratch. It
compares transaction outcomes, ordered observation/effect traces and per-cell
value/revision pairs after every transaction. Cases include scoped/root refusal
and caught defects. Focused engine tests cover speculative reads, diamond run
counts, failed values, snapshots, effect boundaries, disposal and thread/phase
violations. Floating-point signed-zero and NaN propagation through zip, mapN,
attempt and Equality.by have dedicated regressions.

The full log and SHA-256 manifest are in `c1-static-20261027/`. Source hashes
identify the tested source set independently of the eventual Git commit.

## Independent bounded implementation review

The fresh-context `api_review` agent inspected the implementation and tests
without running builds. It found three gaps: read-only callbacks could reach a
second runtime, caught expired capabilities could avoid poisoning, and composed
equality could suppress signed-zero changes. Corrections added ambient per-thread
phase guards with sticky derivation failures, owner-thread expired-token poisoning,
and equality composition from source signals/key equality. All three gained
regression tests. Re-review found **no remaining blocker in those three fixes**,
conditional on the checks above, which then passed. This bounded review does not
constitute independent review of every Stage 1 semantic requirement.

## Limits and next work

Dynamic flatMap topology is explicitly rejected with `TopologyDeferred`.
Mounted scopes, reconciliation, commands, channels, events, native hosting and
rendering are not implemented by this slice. The runtime retains registered
nodes until close; cancellation removes observers/effects, not graph nodes.
It scans/sorts graph metadata and copies the candidate map on each publication;
only affected derivations execute, but whole-graph traversal and large-graph
performance remain unqualified. The reference model currently covers integer
static DAGs, not command outcomes or live ownership/resource sets.

Next: C1.2c topology edits with fixed topology per pass, followed by C1.5 scope
ownership/disposal and an expanded reference oracle. Full Stage 1 exit still
requires all roadmap laws, independent semantic review and real-API corpus review.
The separate upstream GC pause gate remains open; these tests do not qualify it.
