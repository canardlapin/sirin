adapter** on macOS arm64. Full P0.8 acceptance remains open.

native ownership and artifact/build-size evidence. The probe is an isolated
process with ICU4X as its only Rust static library, not a host integration.

extends the bounded component, without certifying L3/L4 glyph behavior, the
separate BidiTest corpus or shared paragraph/editing layout.

Locale-data filtering, isolated data costs, a matched trimmed ICU4C comparison,
full bidi/line layout and production unified-native integration remain open.
Do not use this receipt to clear the existing Stage 0 integration or pause gates.
