## Set up on a new machine

```sh
git clone git@github.com:canardlapin/sirin.git && cd sirin
native/fetch.sh            # pinned wgpu-native + SDL3, SHA-256 checked (macOS / Linux / Windows)
sbt testJVM testNative examples/compile probeWindow/test probeThreads/test
```

The `canardlapin` push identity is repo-local. Set it up with the
`github-account-switch` skill: SSH alias `github-canardlapin`, commit email
from the account registry. Mote is in `.mote/`. The installed Mote 0.1.0
does not provide `mote admit`. After cloning an existing store, restore its
gitignored local directories and select a distinct actor:

```sh
mkdir -p .mote/tmp .mote/local
mote actor set <your-session-name>
mote doctor
mote ready
```

Keep the tracked `.mote/FORMAT.json` and `.mote/ops/` history intact.
